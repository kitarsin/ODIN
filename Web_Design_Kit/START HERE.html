1 Start in four steps

  1. Read 7 Website Today/landing_page_copy.md and look at the screenshots next to it. That is the content you're designing around. The words stay; the look changes.
  2. Install the two fonts in 1 Fonts (right-click each .ttf → Install) so Figma, Photoshop or Canva can use them.
  3. Open 10 Web Code/components-demo.html in a browser. It shows the game's panel, dialogue box, buttons, pixel art and a clip, built only from this kit's CSS.
  4. Design with the pieces in folders 2 to 6 and 9. For anything new in the same pixel style, use 8 Make Your Own, or build it in CSS with 10 Web Code/odin-web.css.

2 The ground rules

Don't change the content

Keep every heading, paragraph, number, button label, link and the section order from landing_page_copy.md. Moving things around inside a section, splitting text into cards, adding pictures and changing the styling are all fine. Rewording is not, unless the team agrees.

The study results (+1.14 and 4.25/5) must always sit next to their caveat, and the footer disclaimer ("ODIN does not diagnose…") must stay.

  1. Pixel art is enlarged by whole numbers only. Show art at the size of the file you picked (@2x, @3x, @4x) and add image-rendering: pixelated. Never let the browser scale it to a width like 100% or 37vw: the pixels smear.
  2. Dark navy background, game panels on top. Panels are the game's code editor: dark grey box, blue border, a header strip with a white title on the left and a grey label on the right.
  3. Colour has a job. Cyan = ODIN and highlights. Gold = key numbers. Red = errors only. Green = success. The five behaviours and the four levels keep their own colours.
  4. Pixel fonts for flavour, a normal font for reading. ODIN Pixel for labels, buttons, code and short text; Dedicool for titles, names and what characters say. Long paragraphs stay in a readable font (the site uses Inter).
  5. Both themes. The site has a dark mode and a Light mode toggle. Design dark first, then check that light mode still reads (use poster_navy for dark text on light backgrounds).
  6. Desktop first, phone friendly. The game needs a keyboard, so the landing page is the main thing phone visitors see. It must work at 390 px wide with no sideways scrolling.
  7. Move like the game. Quick pops (about 0.25 s), text that types itself out, stepped motion. Nothing slow, nothing spinning. Respect prefers-reduced-motion.

Do: use the GIFs and MP4 clips for motion, they're light and already in style.

Don't: stretch or blur sprites, add soft glows to pixel art, use other display fonts, or use the screenshot numbers as real results (see notes).

6 Using it in the code

The website is React + Vite + Tailwind v4. The landing page is two files:

FileWhat it is
src/app/pages/LandingPage.tsxThe structure and all the text. Change class names and wrappers freely; keep the words.
src/app/pages/LandingPage.cssThe landing page's styles, including .light-mode overrides. Most of the redesign happens here.
src/styles/theme.cssSite-wide colours for dark and light mode, used by every other page. Change last, and check the other pages after.

Bringing kit files into the site

  1. Copy only the files you use: fonts into public/fonts/, images into src/img/ (imported, like the logo is now) or public/ (big videos). Don't import straight from Web_Design_Kit.
  2. Paste the @font-face rules and the :root colours from odin-web.css into src/styles/fonts.css and theme.css, fixing the font paths to /fonts/….
  3. Optional: paste tailwind-theme-snippet.css into an @theme block to get classes like bg-odin-deep and text-odin-cyan.
npm install
npm run dev        # http://localhost:5173
npm run build      # check it builds before pushing

This kit folder is about 33 MB. Keep it out of the deployed site; if it goes into git, ask the team first.

8 Make your own elements

The element maker draws new panels, dialogue boxes, headings, cards and tags with the same code as the AVP, so they match exactly.

pip install pillow numpy          # once
cd "8 Make Your Own"
python make_elements.py            # everything in elements.json
python make_elements.py --only my_panel

Edit elements.json (copy an example, change the words). PNGs appear in 8 Make Your Own/out at @2x, @3x and @4x. The full list of options is in section 7 of the Slides Kit's START HERE.html (Thesis4\Slides_Kit). For the web, prefer CSS for anything with text people need to read or translate, and use the maker for decorative pieces.

Drawing pixel art yourself: Aseprite, LibreSprite or Piskel with ODIN palette.gpl loaded. Export enlarged by whole numbers with no smoothing.

9 Notes and checks

  • Game screenshot numbers aren't results. The screenshots were taken with the server's replies typed in by hand: "Level 2 Mastery: 92%" and "+50 XP" are example numbers. The only results on the site are the two in the research section.
  • The hero's game window on the current site is labelled ILLUSTRATIVE PREVIEW. If you swap it for real screenshots or clips from this kit, the label can go; if you keep a mock-up, keep the label.
  • QR code: odin_website_qr_cyan.png holds insomnicode-odin.vercel.app/.
  • Dedicool is by Alexis Lefrançois and ships with the game; ODIN Pixel was made from the AVP's 5×7 letters. FEU logos and the SDG 4 badge belong to their owners; use them only as they appear on the poster.
  • Before calling it done: dark and light mode, 390 px phone width, keyboard focus visible on every link and button, and npm run build passes.
